# README

## Analog Building Blocks

  
This repository contains designs for standard analog circuits and building blocks.

  
It serves as a collection with various analog designs located in its own directory. Each design folder includes its own detailed README, complete with design, specifications, and simulation results. The main aim of the repository is to understand and learn the design process for each of the circuits and the trade-offs involved, and analyze the deviations from hand calculations. The design process will utilize various MOS models ranging from level 1 model to BSIM3/BSIM4 models. Each model provides a trade-off between intuition and realism.
